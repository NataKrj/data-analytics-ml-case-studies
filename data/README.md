# Data files

This folder contains the datasets used by the case studies in this repository.

- `auto_mpg.csv` — Vehicle Fuel Efficiency Analysis
- `california_housing.csv` — California Housing Market Segmentation and Housing Segment Classification
- `kc_house_data.csv` — House Price Prediction & Feature Analysis

The House Price Prediction notebook also creates `kc_house_data_eu_units.csv` during execution after converting selected measurements from square feet to square metres.
